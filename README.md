# 遥感影像变化检测系统 V1.0

## 项目简介

遥感影像变化检测系统是一个基于深度学习的智能遥感影像分析平台，采用 MVC 三层架构在单一进程内运行。系统自动识别影像地理坐标：带坐标的影像保留坐标系并导出矢量，无坐标影像输出普通图像。广泛应用于城市规划、环境监测、灾害评估等领域。

## 技术栈

### 🧠 深度学习 & AI
- **PyTorch 2.8.0** - 核心深度学习框架
- **CUDA 12.6** - GPU 并行计算加速
- **X3D 模型** - 3D 卷积神经网络架构

### 🌍 地理信息系统 (GIS)
- **GDAL** - 地理空间数据抽象库
- **GeoPandas** - 地理空间数据分析
- **Rasterio** - 栅格影像处理

### 🖥️ 前端界面
- **PySide6** - 现代 Qt 框架
- **响应式布局** - 四区域设计
- **主题系统** - 深色/浅色主题切换

### 🐳 环境管理
- **Conda** - Python 环境与依赖管理
- **NVIDIA CUDA** - GPU 加速运行时

## 功能特性

### 🎯 变化检测能力
- **单影像处理** - 自动识别坐标，决定是否保留地理参考
- **批量处理** - 大规模影像对批量分析（每对独立探测坐标）
- **矢量导出** - 仅带坐标影像导出 Shapefile、GeoJSON

### 🖼️ 影像处理
- **多格式支持**：PNG、JPG、JPEG、TIFF、GeoTIFF
- **坐标自动探测**：带坐标→GeoTIFF 掩膜+矢量；无坐标→PNG 掩码
- **可缩放显示** - 支持鼠标滚轮缩放、拖拽平移

### 🎨 用户界面
- **单入口** - 统一影像流程，无需手动选择图像/影像模式
- **主题切换** - 支持深色/浅色主题
- **实时日志** - 处理过程实时显示

### ⚡ 性能优化
- **GPU 加速** - CUDA 并行计算
- **模型懒加载** - 首次检测时加载并缓存复用
- **进程内调用** - 取消 HTTP 层，零网络开销

### 项目结构

系统采用 **MVC 三层架构**，前端通过 Controller 在同一进程内直接调用 Backend：

```
RSCD/
├── Frontend/                # 视图层 - PySide6/Qt6 桌面端
│   ├── app.py               #   主窗口与首页（统一入口）
│   ├── widgets.py           #   可缩放影像显示与导航
│   ├── theme.py             #   深色/浅色主题管理
│   └── views/               #   功能视图（导入/检测/批量/渔网/训练）
│       └── common/          #     线程池、线程安全日志、样式、工具
├── Controller/              # 控制层 - 本地任务调度（无 HTTP 层）
│   ├── local_service.py     #   前端调用入口（提交/查询任务）
│   ├── detection_service.py #   统一推理分发（单影像/批量）
│   ├── task_manager.py      #   检测任务状态机（pending→running→completed）
│   ├── training_task_manager.py  # 训练任务调度
│   └── default_args.py      #   集中推理参数配置
├── Backend/                 # 模型层 - X3D 网络 + 推理 + GIS 处理
│   ├── network/             #   Encoder/Decoder/X3D 网络定义
│   ├── processing/          #   单影像/批量推理（自动探测坐标）
│   │   ├── common/          #     模型缓存、坐标探测、滑窗、内存、可视化
│   │   └── raster/          #     GeoTIFF 读写、地理变换、矢量导出
│   ├── training/            #   训练主循环（train_loop）
│   ├── data/                #   数据集类与变换
│   └── evaluation/          #   评估指标（混淆矩阵等）
├── utils/                   # 共享工具（路径解析、共享目录管理）
├── scripts/                 # 脚本（prepare_training_data.py 数据准备）
├── tests/                   # 测试
├── checkpoint/              # 模型权重（X3D_L.pyth / best_model.pth 等）
├── data/                    # 运行时目录（t1/t2/output；数据集未纳入版本控制）
├── start_app.py             # 应用启动入口
└── requirements.txt         # Python 依赖
```

### 部署步骤

#### 1. 克隆项目
```powershell
git clone https://github.com/qianxiR/RSCD.git
cd RSCD
```

#### 2. 安装依赖
```powershell
pip install -r requirements.txt
```

#### 3. 启动桌面应用
```powershell
python start_app.py
```

> 仓库已内置推理所需模型权重（`checkpoint/`），克隆后即可直接运行变化检测，无需额外下载。

#### 4.（可选）准备训练数据集

训练所需数据集未纳入版本控制，请通过脚本自行生成或准备至 `data/` 目录：
```powershell
python scripts\prepare_training_data.py
```

## 使用指南

### 基本操作流程

1. **启动系统**
   - 运行 `python start_app.py`，系统初始化后点击「开始使用」进入主界面

2. **导入影像**
   - 点击「导入前时相影像」选择较早时期的影像（PNG/JPG/TIFF 均可）
   - 点击「导入后时相影像」选择较新时期的影像

3. **执行变化检测**
   - 点击「开始解译」按钮，选择输出目录
   - 系统自动探测影像坐标：带坐标保留地理参考并导出矢量，无坐标输出普通图像

4. **批量处理**
   - 点击「批量处理」按钮
   - 选择前后时相目录与输出目录
   - 每对影像按各自坐标情况独立处理

## 故障排除

### 常见问题

1. **应用启动失败**
   - 检查 Python 版本（需要 3.10+）
   - 确认依赖包安装完整：`pip install -r requirements.txt`

2. **GPU 不可用**
   - 确认已安装 NVIDIA 驱动与 CUDA 12.6
   - 验证 PyTorch 可识别 GPU：`python -c "import torch; print(torch.cuda.is_available())"`

3. **矢量导出缺失（GeoTIFF 影像）**
   - 影像需同时具有 GeoTransform 与 Projection 才会导出矢量
   - 确认 GDAL 库已正确安装：`python -c "from osgeo import gdal; print(gdal.__version__)"`
